# Prácticas Back-End: Node.js y Python

Este paquete contiene la implementación práctica estructurada en capas para ambos entornos.

## Instrucciones para Node.js
1. Acceder a `node-backend/`
2. Ejecutar `npm install`
3. Iniciar el servidor en modo desarrollo: `npm run dev`
4. Probar en el navegador o curl: `http://localhost:3000/users/1`

## Instrucciones para Python
1. Acceder a `python-backend/`
2. Crear entorno virtual: `python -m venv venv`
3. Activar entorno virtual: `source venv/bin/activate`
4. Instalación: `pip install -r requirements.txt`
5. Iniciar servidor: `cd src && uvicorn main:app --reload --port 8000`
6. Probar en el navegador o curl: `http://localhost:8000/users/1`
